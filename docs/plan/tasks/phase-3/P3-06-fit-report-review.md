## Why
You are the last check. Each job gets one folder with everything you need to decide and apply, and `review.md` puts each bullet beside its source so a diff-style review is fast.

## What to do
- [ ] `applications/YYYY-MM-DD_<company>_<role>/` with `jd.md`, `fit-report.md`, `cv.yaml`, `cv.pdf`, `cv.docx`, `cover-letter.md`, `cover-letter.pdf`, `review.md`, `status.json`.
- [ ] `fit-report.md`: each job requirement marked ✔ present (claim IDs), ≈ adjacent (honest wording), ✘ missing. Missing skills are never added to the CV.
- [ ] `review.md`: each bullet beside its source text, qualifier changes highlighted, all P3-02/P3-03 findings.
- [ ] `status.json`: `job_uid`, `state` (draft → ready → applied-by-user → outcome), history, verdict, score, `submitted_by_user`.

## Done when
- A folder for one real job contains every file above and `review.md` shows every bullet with its source.
